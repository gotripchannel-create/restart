# Заявки с сайта → в Telegram (бесплатно, ~5 минут)

## 1. Создайте бота
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя (например, «Рестарт заявки»).
2. BotFather пришлёт **токен** вида `123456789:AAF...`. Сохраните его.
3. Найдите своего нового бота в поиске и нажмите **Start** (иначе он не сможет вам писать).

## 2. Узнайте свой chat_id
Напишите боту **@userinfobot** — он ответит числом `Id: 123456789`. Это ваш chat_id.
(Для группы: добавьте бота в группу, chat_id группы начинается с `-100…`.)

## 3. Разверните приёмник в Google Apps Script
1. Откройте https://script.google.com → **Новый проект**.
2. Удалите всё и вставьте код из `apps-script.gs`.
3. Впишите `BOT_TOKEN` и `CHAT_ID` в начале файла → 💾 Сохранить.
4. Выберите функцию `testMessage` → **Выполнить** → разрешите доступ. В Telegram придёт тестовая заявка.
5. **Развернуть → Новое развертывание → тип «Веб-приложение»**:
   - Выполнять как: **Я**
   - Доступ: **Все**
6. Скопируйте **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).

## 4. Подключите к сайту
Вставьте этот URL в админке: «Заявки» → «Адрес приёмника заявок» → Save
(или отправьте его Claude). Готово: каждая заявка придёт в Telegram и сохранится в Google-таблицу «Заявки Рестарт».
