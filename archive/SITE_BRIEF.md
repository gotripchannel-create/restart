# ТЗ: перенос сайта «Рестарт» с Flexbe

## Исходные данные
- Проект Flexbe 767519 (lp767519.myflexbe.ru), заблокирован, будет удалён 11.11.2026.
- Боевая страница — `/` («Духовная трансформация с Вималанандой | Психология, Аюрведа, Йога | Проект Рестарт»).
- Ещё 7 страниц — недоделанные черновики-заготовки (шаблонные «First Service $1000», выдуманные адреса/телефоны). В навигации их нет. Сохранены в `backup/`, не публикуются.
- Бэкап: `backup/flexbe_html/` (полный HTML 8 страниц), `backup/img/` (115 оригиналов), `backup/content/` (текстовая выжимка).

## Цель
Бесплатный хостинг (GitHub Pages), дизайн 1:1, контент без потерь, удобное редактирование
(админка Pages CMS или правки через Claude), заявки в Telegram, высокая скорость и SEO.

## Дизайн-система (снято с оригинала)
- Шрифты: Unbounded 500/700 (заголовки), Inter 400/500/700 (текст).
- Цвета: текст #252525 / #060607; акцент-оранжевый #F09143 (кнопки, плашки), тёмный оранжевый #E39C61 (карточки цифр),
  кнопка формы #FF6C46; персиковый фон секций #FFE1BA (смягчённый #FAE1BE); жёлтые плашки этапов #FCDA85; серый фон #F5F5F5.
- Скругление карточек ~16–20px, мягкие тени rgba(0,0,0,.07), контейнер 1150px.
- Эффекты: hover-зум фото в карточках, появление при скролле, плавный скролл к якорям, фиксированная шапка, аккордеон, табы.

## Структура (порядок секций как в оригинале)
1. Шапка: меню + соцсети (Instagram, Telegram, YouTube, Facebook), фикс. при скролле, бургер на мобильном.
2. Hero-мозаика: большая карточка «Рестарт — путь к внутренней свободе» + кнопка «Бесплатная консультация»; карточки Методика / Традиция / Команда.
3. О проекте (белая карточка на персиковом фоне).
4. Цифры: 8 экспертов / 99% / 24 месяца.
5. Команда: 5 специалистов с фото и тезисами + «Подробнее».
6. Системный подход.
7. Этапы работы (5 шагов, жёлтые плашки).
8. Стоимость: табы STARTER / БАЗОВЫЙ / УГЛУБЛЕННЫЙ / ПРЕМИУМ, по 4 карточки, иконка «Ом», плашки срок+цена.
9. Результаты трансформации: фото + аккордеон из 5 уровней.
10. Форма «Начните путь к гармонии» (Имя, Телефон*, Email*).
11. Отзывы (4).
12. Подвал: меню, контакты, соцсети.
13. Модалка «Бесплатная консультация» + окно «Спасибо за заявку».

## Улучшения (без изменения дизайна)
- Исправить якоря меню (в оригинале вели не туда), добавить «Вималананда» → карточка основателя, «Команда» → команда.
- Явные опечатки: двойное «04» в этапах → 05; повтор пункта у Ирины; мусор «ошибки ПО»; обрыв «полное погружение в».
- Мобильная версия, плавающая кнопка связи в Telegram, маска телефона, валидация, SEO-мета, Open Graph, favicon, sitemap.
- Сжатые изображения (87 МБ → несколько МБ), lazy-loading.

## Техническая схема
- `content/site.json` — ВСЕ тексты, цены, фото, контакты (единственное место правок).
- `build.py` (Python, без зависимостей) собирает `site/index.html` из `templates/` + `content/site.json`.
- GitHub Actions: при каждом изменении собирает и публикует на GitHub Pages.
- `.pages.yml` — конфиг админки Pages CMS (app.pagescms.org, вход через GitHub).
- Заявки: Google Apps Script (на Gmail владельца) → Telegram-бот; токен бота не хранится в коде сайта.
