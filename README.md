# Сайт проекта «Рестарт»

Перенесён с Flexbe (проект 767519) на бесплатный хостинг GitHub Pages.

## Как править сайт

**Вариант 1 — через админку (без кода).**
1. Откройте https://app.pagescms.org и войдите через GitHub.
2. Выберите репозиторий `restart` → «Содержимое сайта».
3. Поменяйте текст, цены, фото или контакты → **Save**.
4. Через 1–2 минуты изменения появятся на сайте автоматически.

**Вариант 2 — через Claude.** Напишите, что поменять («обнови цену пакета ПРЕМИУМ на 2100$»),
Claude отредактирует `content/site.json` и опубликует.

## Где что лежит
| Что | Где |
|---|---|
| Все тексты, цены, контакты, ссылки на фото | `content/site.json` |
| Фотографии сайта | `static/img/` |
| Дизайн (цвета, шрифты, отступы) | `static/style.css` |
| Поведение (меню, табы, формы) | `static/main.js` |
| Шаблон страницы | `build.py` |
| Админка | `.pages.yml` |
| Автопубликация | `.github/workflows/deploy.yml` |
| Приём заявок в Telegram | `telegram/` |
| Полный архив сайта с Flexbe | `archive/` |

## Заявки в Telegram
Инструкция: [telegram/README.md](telegram/README.md). Пока приёмник не настроен,
кнопка формы отправляет посетителя в Telegram `t.me/Yoga_Chiangmai`, так что заявки не теряются.

## Локальная сборка
```bash
python3 build.py && python3 -m http.server -d _site 8000
```
